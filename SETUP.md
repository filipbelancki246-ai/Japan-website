# Подключение (только фронтенд, без серверов)

## Файлы сайта (всё в одной папке с index.html)
| Файл | Зачем |
|---|---|
| `index.html` | ваш сайт |
| `sd-extras.js` | все новые функции |
| `sw.js`, `manifest.webmanifest`, `icon.svg` | установка сайта как приложения (PWA) и иконка |
| `menu.json` | общее меню, акции, отзывы, галерея (создаётся из админки) |
| `images/` | ваши фото в WebP (по желанию) |

## 1. Подключить скрипт
Вставьте в `index.html` **перед последним `<script>`** (тем, что начинается с `(function(){ "use strict";`):
```html
<script src="sd-extras.js"></script>
```

## 2. SEO
Откройте `SEO-head.html`, скопируйте блок в `<head>` вашего `index.html` и замените `ВАШ-САЙТ` и контакты. Добавьте картинку `preview.jpg` (1200×630) для превью в соцсетях.

## 3. Настройки
В начале `sd-extras.js`, блок `CONFIG`:
- `DELIVERY`: цена доставки, сумма бесплатной доставки, минимальный заказ (₩).
- `HOURS`: часы работы и часовой пояс для метки «Сейчас открыто».
- `CONTACT`: телефон, почта, Telegram (без @), адрес. Карта строится по адресу, отключить: добавьте `MAP:false`.

## 4. Меню, акции, отзывы, галерея для всех посетителей
1. Войдите в админку (Ctrl+Shift+A, пароль из `index.html`).
2. Добавляйте блюда (с категорией, описанием, бейджами), отзывы и фото интерьера.
3. Нажмите **«Скачать menu.json»** и загрузите файл на хостинг рядом с `index.html`.

Свои фото: положите файлы в папку `images/` и в поле фото укажите `images/steak.webp`.
Акции правятся в `menu.json` в массиве `promos`.

## Как работает заказ
Гость выбирает доставку или самовывоз, способ оплаты (наличные, карта при получении, перевод), время и комментарий. Номер карты на сайте больше не вводится. После оформления появляется кнопка «Отправить заказ в Telegram» с готовым текстом.

## Ограничения (без сервера иначе нельзя)
- Заказ уходит в Telegram, только если гость сам нажмёт «Отправить».
- Пароль админки виден в коде; на других посетителей он не влияет, пока меню берётся из вашего `menu.json`.
- Промокоды проверяются в браузере.
- «Установить как приложение» и работа офлайн включаются только на https-хостинге, не при открытии файла с диска.
